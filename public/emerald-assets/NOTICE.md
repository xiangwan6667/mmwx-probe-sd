# Emerald local image assets

- `flags/`: 4:3 SVG flags copied unchanged from the installed `flag-icons` package (MIT). See `LICENSE-flag-icons.txt`.
- `os/`: selected SVG icons copied unchanged from the installed `simple-icons` package (CC0-1.0 collection). Original source URLs, brand guidelines and any individual icon license metadata are preserved in `simple-icons-metadata.json`. See `LICENSE-simple-icons.md` and `DISCLAIMER-simple-icons.md`.
- `os/unknown.svg`: project-authored generic computer icon. Used for Windows because the installed Simple Icons version does not include its logo. Distributions without a bundled brand icon use the Linux icon (OpenWrt derivatives use OpenWrt).

These files are served locally by this theme; the notice covers only these bundled images. Other Emerald resources (including Iconify icons, map data, and exchange-rate data) may still use external requests. Existing image dimensions and CSS remain unchanged. Brand and flag artwork retain their respective owners' rights.
